# CodeNexus

A college-exclusive developer social platform for competitive programming at IET Lucknow. 

## Features 
 - Secure login with Google OAuth (College-only access)
 - Competitive programming stats (Codeforces, Leetcode, CodeChef)
 - Real-time Leaderboard with filters (year, branch, global)
 - Follow system to connect with peers
 - Real-time 1-on-1 messaging 
 - Activity tracking and rating history

 ## Tech Stack 
 - **Frontend**: Next.js + Tailwind CSS (Deployed on Vercel)
 - **Backend**: Node.js + Express + Socket.io (Deployed on Render)
 - **Database**: Supabase (PostgreSQL)
 - **Auth**: Google OAuth 2.0 + JWT
 - **CP APIs** Codeforces, Leetcode GraphSQL, CodeChef
